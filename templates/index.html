How it was built

Leafwise uses a convolutional neural network, GoogLeNet, that was first trained on millions of everyday photos (ImageNet) and then fine-tuned on the PlantVillage dataset. That second step is called transfer learning, and it is why a small student project can reach high accuracy.

Photos were resized to 256 × 256 pixels and randomly flipped, rotated and brightness-shifted while training, so the model copes with different angles and lighting. We kept all photos of the same leaf together in either the training set or the test set, so the test score isn’t inflated by the model seeing the same leaf twice.

Where it can struggle

PlantVillage photos were taken indoors on a plain background. Real field photos, with soil, shadows and other leaves behind, are harder, so expect lower confidence there. Photograph one leaf against a plain surface for the best results.
